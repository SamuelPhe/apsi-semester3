# EduSched — GitHub Codespaces

This setup runs the original PHP application in Apache and imports the database structure into a local MariaDB container.

## Open the web application

1. Open this repository on GitHub.
2. Select **Code → Codespaces → Create codespace on main** (or resume the existing EduSched Codespace).
3. Wait for the containers to finish starting.
4. Open the **Ports** tab in the Codespaces editor.
5. Find **EduSched web (private)**, port `8080`, and choose **Open in Browser**.
6. The original application login screen is served at `/login.php`.

Apache serves the PHP application from the repository's `apsib/` directory. MariaDB imports `apsib/database/schema.sql` into the `edusched` database.

## Login notes

The schema contains table definitions only; it does not contain a user account. There is no demo username or password. To sign in, create a local row in `users` with a password generated by PHP `password_hash()` and a valid `admin` or `guru` role. The login page itself can be viewed without an account.

Keep port `8080` **Private**. Do not upload real students' information, exam materials, or personal profile data.

If this Codespace was created before the web service/port was added or updated, open the Command Palette and run **Codespaces: Rebuild Container**. This applies the current Compose configuration; it does not require deleting the Codespace or its named database volume.

## Stop and resume

Stop the Codespace when finished. When resumed, the web and database services start again. MariaDB data remains in its named volume while the Codespace and volume are retained.
